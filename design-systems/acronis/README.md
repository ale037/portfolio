# Acronis Design System

Унифицированная дизайн-система для веб- и десктопных продуктов международного лидера в сфере киберзащиты Acronis.

- **Компания:** Acronis
- **Организация на GitHub:** [https://github.com/acronis](https://github.com/acronis)

- Статья 2: *«Дизайн–система Acronis. Часть вторая. Иконки, SVG шрифты, Gulp»*, Сергей Никишкин — [Habr](https://habrahabr.ru/company/acronis/blog/344454/)

## Архитектура и технологии
- Единый репозиторий компонентов, иконочные шрифты, оптимизация SVG и автоматизированная сборка.
- Строгий технологичный стиль: глубокий тёмно-синий `#002447`, акцентный защитный голубой `#2060ff`.
- Кроссплатформенная поддержка облачных сервисов резервного копирования и корпоративной безопасности.
