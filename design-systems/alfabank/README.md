# Дизайн Альфа-Банка (Alfa-Bank Design System)

Дизайн-система одного из крупнейших частных банков России.

- **Компания:** Альфа-Банк
- **Официальный сайт:** [http://design.alfabank.ru/](http://design.alfabank.ru/)
- **Репозиторий с кодом:** [https://github.com/core-ds/core-components](https://github.com/core-ds/core-components) (Alfa Core Components)
- **Организация на GitHub:** [https://github.com/alfalab](https://github.com/alfalab)

## Материалы и презентации с designsystemsclub.ru
- Доклад: *«Собственная система прототипирования на основе веб-компонентов»* (Я. Саверин, В. Галахов) — [YouTube](https://www.youtube.com/watch?v=2Mp6DD-gUjU)

## Стек и архитектура
- React, TypeScript, Styled Components / Emotion / CSS Modules
- Атомарные дизайн-токены (цвета, шрифты Alfa Sans, отступы, сетки)
- Поддержка доступности (A11y) и строгая корпоративная стилистика в фирменном красном цвете `#ef3124`.
