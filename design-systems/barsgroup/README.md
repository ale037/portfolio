# BARS Group Design System

Дизайн-система крупного федерального разработчика программного обеспечения для государственного сектора и бизнеса.

- **Компания:** БАРС Груп (BARS Group)
- **Официальный сайт дизайн-системы:** [https://design.bars.group/](https://design.bars.group/)
- **Статус репозитория:** Корпоративная закрытая кодовая база

## Описание из каталога designsystemsclub.ru
Дизайн-команда крупного федерального разработчика работает над унификацией масштабных продуктов для государства и бизнеса.

## Особенности архитектуры
- Фокус на высокой плотности данных (Data-heavy interfaces), таблицы, аналитические дашборды.
- Строгая цветовая палитра на основе корпоративного синего `#0066b3` и нейтральных оттенков.
- Оптимизация под работу в госучреждениях и ERP-системах.
