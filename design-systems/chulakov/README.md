# Дизайн-система Студии Олега Чулакова

Платформа для создания корпоративных сайтов и цифровых сервисов одной из ведущих интерактивных студий России.

- **Компания:** Студия Олега Чулакова (Chulakov Studio)
- **Официальный сайт дизайн-системы:** [https://design.chulakov.ru/](https://design.chulakov.ru/)
- **Статус репозитория:** Внутренняя модульная платформа Студии

## Описание из каталога designsystemsclub.ru
Платформа для корпоративных сайтов Студии.

## Особенности
- Высокие требования к типографике, микроанимациям и эстетике.
- Современные интерактивные паттерны и гибкая сеточная система.
