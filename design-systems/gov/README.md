# Дизайн Государственных Систем (Gov Design)

Единая платформа и стандарты проектирования интерфейсов для сайтов государственных органов, ведомств и учреждений РФ.

- **Организация:** AIC, Минцифры РФ
- **Официальный сайт:** [http://gov.design/](http://gov.design/)
- **Организация на GitHub:** [https://github.com/govdesign](https://github.com/govdesign)
- **Блог:** [http://blog.gov.design/](http://blog.gov.design/)

## Репозитории на GitHub
- [govdesign/symbols](https://github.com/govdesign/symbols) — библиотека символов, иконок и UI компонентов.
- [govdesign/awesome-gov](https://github.com/govdesign/awesome-gov) — курируемый список государственных дизайн-систем и инструментов.
- [govdesign/blog](https://github.com/govdesign/blog) — материалы и статьи блога платформы.
- [govdesign/wishlist](https://github.com/govdesign/wishlist) — список пожеланий и требований.

## Принципы дизайна
- Высокая контрастность и соблюдение стандартов доступности для всех групп граждан (WCAG / ГОСТ).
- Фирменный государственный синий `#0072db` и строгая государственная айдентика.
- Четкая информационная иерархия без визуального шума.
