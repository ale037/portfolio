# Ivi.ru Design System

Кроссплатформенная дизайн-система ведущего отечественного онлайн-кинотеатра ivi.

- **Компания:** ivi.ru
- **Официальный сайт:** [https://design.ivi.ru/](https://design.ivi.ru/)
- **Статус репозитория:** Внутренняя кодовая база

## Материалы и статьи с designsystemsclub.ru
- Статья: *«От UI-kit до дизайн-системы. Опыт онлайн-кинотеатра Иви»*, Илья Хромов — [Medium](https://link.medium.com/Jl6VDhQj0X)

## Особенности архитектуры
- Мультиплатформенность: поддержка Web, мобильных приложений (iOS, Android) и Smart TV интерфейсов.
- Фирменная тёмная тема для кинематографического погружения, акцентный гранатово-красный `#ea144c`.
- Оптимизация навигации под пульты ДУ и фокусные состояния элементов.
