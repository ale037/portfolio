# Контур.Гайды и React UI (SKB Kontur Design System)

Первоисточник требований к дизайну интерфейсов экосистемы Контура и библиотека компонентов для сложных B2B SaaS-продуктов.

- **Компания:** СКБ Контур
- **Официальный портал гайдлайнов:** [https://guides.kontur.ru/](https://guides.kontur.ru/)
- **Репозиторий на GitHub:** [https://github.com/skbkontur/retail-ui](https://github.com/skbkontur/retail-ui) (ранее retail-ui, ныне `@skbkontur/react-ui`)
- **Живая витрина компонентов:** [http://tech.skbkontur.ru/react-ui/](http://tech.skbkontur.ru/react-ui/)

## Материалы и публикации с designsystemsclub.ru
- Статья: *«Скетч-библиотека для работы»*, Александр Храмцов — [Medium](https://medium.com/designkontur/скетч-библиотека-для-работы-19a692ea959f)

## Стек и архитектура
- React, TypeScript, Lerna monorepo, CSS-in-JS.
- Мощная система темизации (`ThemeContext`, `LIGHT_THEME`, `DARK_THEME`).
- Исключительная оптимизация под работу со сложными формами, таблицами данных и бухгалтерскими интерфейсами.
