# Paradigm (Mail.Ru Group / VK Design System)

Дизайн-система экосистемы Mail.Ru Group (ныне VK), одна из родоначальниц движения дизайн-систем в России.

- **Компания:** Mail.Ru Group / VK
- **Официальный сайт:** [http://design.mail.ru/paradigm/](http://design.mail.ru/paradigm/)
- **Репозитории с кодом:**
  - [VKCOM/VKUI](https://github.com/VKCOM/VKUI) — основная открытая библиотека UI компонентов экосистемы VK
  - [VKCOM/paradigm-tokens](https://github.com/VKCOM/paradigm-tokens) — кроссплатформенные дизайн-токены Paradigm
  - [mailru/designsystemsclub](https://github.com/mailru/designsystemsclub) — открытый каталог дизайн-систем

## Особенности архитектуры
- Многоуровневые дизайн-токены (Global, Semantic, Component).
- Поддержка тем оформления (Светлая, Тёмная, Почтовые темы).
- Мобильно-ориентированный подход и высочайшая скорость рендеринга.
