# МегаФон UI (Megafon Design System)

Дизайн-система одного из ведущих российских телеком-операторов.

- **Компания:** ПАО «МегаФон»
- **Официальный сайт дизайн-системы:** [http://ui.megafon.ru/](http://ui.megafon.ru/)
- **Статус репозитория:** Внутренняя система телеком-платформы

## Материалы и публикации с designsystemsclub.ru
- Статья: *«Дизайн-система МегаФона. Эпизод 1: Процессы и инструменты»*, Надежда Терехова, Артём Володин, Станислав Петров — [Medium](https://medium.com/@ux.ui.megafon/дизайн-система-мегафона-эпизод-1-процессы-и-инструменты-ab6970d58483)

## Область применения и архитектура
- Портал, интернет-магазин, мобильный личный кабинет и цифровые гайдлайны бренда.
- Узнаваемая цветовая гамма: фирменный зелёный `#00b956` и контрастный фиолетовый `#731982`.
- Высокая скорость загрузки и адаптивность под мобильные устройства абонентов.
