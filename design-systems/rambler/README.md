# Rambler UI (Rambler&Co Design System)

Библиотека React-компонентов Rambler UI, разработанная для создания веб-интерфейсов группы компаний Rambler&Co.

- **Компания:** Rambler&Co
- **Официальный сайт бренда:** [https://brand.rambler.ru/](https://brand.rambler.ru/)
- **Репозиторий на GitHub:** [https://github.com/rambler-digital-solutions/rambler-ui](https://github.com/rambler-digital-solutions/rambler-ui)
- **Живая витрина компонентов:** [https://rambler-digital-solutions.github.io/rambler-ui/](https://rambler-digital-solutions.github.io/rambler-ui/)

## Материалы и публикации с designsystemsclub.ru
- Статья: *«Разработка единой дизайн-системы — опыт «Рамблера»»*, Юлия Зоркина — [vc.ru](https://vc.ru/28213-razrabotka-edinoy-dizayn-sistemy-opyt-ramblera)

## Стек и архитектура
- React, TypeScript, React-JSS (CSS-in-JS).
- Полнофункциональная дизайн-система с поддержкой тем оформления (`ThemeProvider`).
- Фирменный Rambler Blue `#315efb` и строгая портальная типографика.
