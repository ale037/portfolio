# Tinkoff Design System / Taiga UI

Дизайн-система одного из самых передовых финтех-банков России (Т-Банк / Тинькофф).

- **Компания:** Т-Банк (ранее Тинькофф)
- **Основной открытый репозиторий:** [https://github.com/taiga-family/taiga-ui](https://github.com/taiga-family/taiga-ui) (ранее Tinkoff Taiga UI)
- **Организация на GitHub:** [https://github.com/Tinkoff](https://github.com/Tinkoff)

## Архитектура и особенности
- Полный набор модулей для Angular и React, мощный монорепозиторий Nx, открытая кодовая база Taiga UI.
- Фирменный жёлтый цвет `#ffdd2d`, выразительная геометрия скруглений, поддержка темных и светлых тем.
- Передовые паттерны финансового интерфейса: инпуты денежных сумм, маски карт, валидация.
