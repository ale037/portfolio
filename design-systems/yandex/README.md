# Лего и БЭМ (Яндекс / BEM Design)

Платформа от создателей всемирно известной методологии БЭМ (Блок, Элемент, Модификатор) для унификации веб-сервисов Яндекса.

- **Компания:** Яндекс
- **Официальный сайт методологии:** [https://ru.bem.info/](https://ru.bem.info/)
- **Платформа BEM Design:** [http://bem.design](http://bem.design)
- **Репозитории с кодом на GitHub:**
  - [bemdesign](https://github.com/bemdesign) — библиотека масштабируемого дизайна на основе БЭМ
  - [kovchiy/beast](https://github.com/kovchiy/beast) — декларативный инструмент создания интерфейсов
  - [yandex/dpt](https://github.com/yandex/dpt) (Depot) — фреймворк для дизайнеров интерфейсов

## Архитектура и принципы БЭМ
- Строгая компонентная декомпозиция (Блоки, Элементы, Модификаторы).
- Независимость блоков и переиспользуемость между сервисами (Поиск, Карты, Маркет, Музыка).
- Фирменный жёлтый акцент `#ffcc00`, строгий чёрный `#000000` и лаконичный дизайн.
